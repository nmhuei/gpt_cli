5. Safe MCP rollback, granular `DeleteResult`, upfront permission validation, and clean stdout JSON output.
6. Multi-turn history formatting and graceful cancellation propagation in the Gateway server.

```python
import fcntl
import os
import tempfile
from contextlib import contextmanager

@contextmanager
def _file_lock(lock_path: Path):
    lock_path.parent.mkdir(parents=True, exist_ok=True)
    with open(lock_path, "w") as f:
        fcntl.flock(f.fileno(), fcntl.LOCK_EX)
        try:
            yield
        finally:
            fcntl.flock(f.fileno(), fcntl.LOCK_UN)
```
